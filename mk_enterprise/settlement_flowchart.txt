# Settlement Data Flow & Grouping Logic

Here is the current architecture of how Settlements are generated, fetched, and grouped in the Admin profile.

1. How Settlements are Created
   - User generates Invoice -> Auto-creates Settlement Entry (Type: Income, Cat: today_invoice)
   - User clears Pending Due -> Auto-creates Settlement Entry (Type: Income, Cat: due_cleared)
   - User clicks 'Add Entry' -> Manually creates Settlement Entry (Expense / Income / Supplier)

2. Backend Database
   - Stores in MongoDB: Settlements Collection
   - Fields: Amount, Mode, Notes, Type, Manager ID

3. Admin Dashboard (Real-time Fetching)
   - 10-second polling to Backend API
   - Fetches Data & Manager Names to Admin Dashboard

4. Admin UI Display
   - Summary Cards (Total Received, Paid Out, Net)
   - Full History Table (Lists ALL individual entries)
   - Click Received/Paid Out -> Dropdown Summary Panel
     - Groups by Manager Name
       - Groups by Mode of Payment (CASH, UPI, CHEQUE)
         - Displays Total Amount for that Mode
         - Displays List of specific Notes / Invoices
